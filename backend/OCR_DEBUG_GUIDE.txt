# ═══════════════════════════════════════════════════════════════════════════
# STEP 2: Understand the Problem
# ═══════════════════════════════════════════════════════════════════════════

SCENARIO A: OCR returns garbled text
├─ Cause: Image quality, angle, lighting, or language detection
├─ Fix: Adjust preprocessing (contrast, sharpening, brightness)
└─ Solution: See STEP 3 (Tune Preprocessing)

SCENARIO B: OCR returns blank/empty
├─ Cause: PaddleOCR can't detect text regions
├─ Fix: Image is too small, rotated, or low quality
└─ Solution: Check image dimensions, try rotating, improve lighting

SCENARIO C: OCR works but fields don't match
├─ Cause: Extraction engine can't parse the correct text
├─ Fix: Add keywords/patterns to patterns.py
└─ Solution: See STEP 4 (Tune Extraction Rules)

# ═══════════════════════════════════════════════════════════════════════════
# STEP 3: Tune Preprocessing (If Images Are Blurry/Dark/Wrong)
# ═══════════════════════════════════════════════════════════════════════════

Edit: backend/app.py → preprocess_image() function

Key tuning parameters:

A. Brightness (make text darker/lighter):
   OLD: image = cv2.convertScaleAbs(image, alpha=1.1, beta=20)
   TRY: image = cv2.convertScaleAbs(image, alpha=1.2, beta=30)  # Brighter
   OR:  image = cv2.convertScaleAbs(image, alpha=1.0, beta=10)  # Less bright

B. Sharpening (make text clearer):
   OLD: kernel = np.array([[-1, -1, -1], [-1, 13, -1], [-1, -1, -1]]) / 1.0
   TRY: kernel = np.array([[-1, -1, -1], [-1, 15, -1], [-1, -1, -1]]) / 1.0  # Sharper
   OR:  kernel = np.array([[-1, -1, -1], [-1, 10, -1], [-1, -1, -1]]) / 1.0  # Less sharp

C. Contrast (CLAHE settings):
   OLD: clahe = cv2.createCLAHE(clipLimit=3.0, tileGridSize=(16, 16))
   TRY: clahe = cv2.createCLAHE(clipLimit=4.0, tileGridSize=(16, 16))  # More contrast
   OR:  clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))    # Less contrast

D. Resize (for small text):
   OLD: max_dim = 1600
   TRY: max_dim = 2000  # Larger → captures small text better
   OR:  max_dim = 1200  # Smaller → faster processing

   Example: If "Chocolate Malt" not detected as Beverages

     'Beverages': [
       ...existing keywords...,
       'chocolate malt',  # ADD THIS
     ]

C. Test again:
   python test_ocr.py "C:\path\to\image.jpg"

# ═══════════════════════════════════════════════════════════════════════════
# COMMON ISSUES & QUICK FIXES
# ═══════════════════════════════════════════════════════════════════════════

Issue: "No text detected"
→ Fix: Image is blurry or too small
→ Try: Increase brightness (alpha=1.3, beta=40)
→ Try: Increase sharpening (kernel center = 15)

Issue: "Random gibberish characters"
→ Fix: OCR language not set correctly
→ Status: Already set to 'en' (English) in get_ocr()
→ Try: Preprocessing too aggressive (reduce CLAHE clipLimit)

Issue: "Only half the text extracted"
→ Fix: Image is rotated or has angle
→ Status: Already using use_angle_cls=True
→ Try: Rotate image manually before uploading

Issue: "Fields not matching knowledge base"
→ Fix: Brand name spelling different
→ Try: Add fuzzy matching to knowledge_base lookup (already done)
→ Try: Add brand to knowledge_base.json with correct spelling

Issue: "Backend crashes when processing image"
→ Fix: Image format not supported or corrupted
→ Try: Use .jpg or .png format
→ Try: Compress image to <5MB
→ Check logs: python app.py (will show error)

# ADVANCED: If Still Failing

Option 1: Try different image preprocessing
• Replace current preprocess_image() with simpler version
• Remove some morphological operations
• Test with basic CLAHE only

Option 2: Try different OCR language

Option 4: Increase image size
